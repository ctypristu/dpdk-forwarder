# DPDK 高性能转发与 ACL 过滤系统 · 项目规划书

版本 V1.0 ｜ 2026-09-17

---

## 一、项目定位

这是一个**个人技术项目**，目标有两个：

1. 做出一个能跑、有数据的用户态转发系统
2. 沉淀成一段能写在简历上、经得起面试追问的经历

第二个目标决定了设计上的取舍：**优先保证"能独立完成"和"有可量化结果"**，
而不是追求功能大而全。

---

## 二、目标

### 功能目标

| 模块 | 内容 |
|---|---|
| 收发包 | 基于 DPDK PMD 的用户态收发，多队列 RSS 分流 |
| 报文解析 | Ethernet / IPv4 / IPv6 / TCP / UDP 头部解析 |
| 转发 | L2 转发（MAC 表）+ 可选 L3 转发（FIB） |
| ACL | 五元组规则匹配，支持规则动态增删 |
| 会话 | 会话表建立、查找、超时老化 |
| 统计 | 端口级与规则级计数，定时输出 |

### 性能目标

具体数值以测试平台为准，目标区间：

| 指标 | 目标 |
|---|---|
| 64B 小包吞吐 | ≥ 10 Mpps（单口 10G 线速为 14.88 Mpps） |
| 大包吞吐 | 跑满线速 |
| 相对内核转发 | 吞吐提升 ≥ 3× |
| 单核 CPU 占用 | 相比内核转发路径降低 ≥ 50% |

> 性能数据一律以实测为准，不写估算值。测不出来就写"未达标"并说明原因，
> 这比编一个好看的数字更有价值。

---

## 三、范围

### 做

- 用户态收发包与转发
- 五元组 ACL 与会话跟踪
- 性能优化（多核、无锁、批量、大页、亲和性）
- 系统性测试与数据记录
- 文档与开源

### 不做

- 完整 TCP/IP 协议栈（不做分片重组、不做应用层）
- 路由协议（BGP / OSPF 之类）
- 高可用、热备、集群
- 图形管理界面（用配置文件和命令行参数即可）

**范围边界很重要。** 每加一个功能，完成时间就往后推一周。上面"不做"的清单
是为了保证项目能收尾。

## 四、技术方案

| 项 | 选型 | 理由 |
|---|---|---|
| 语言 | C++17 | 兼顾性能与可维护性 |
| 框架 | DPDK 24.11 LTS | 长期支持版本，生态成熟 |
| 构建 | CMake | 通用，便于别人编译 |
| 并发模型 | 每核独立流水线，无共享状态 | 避免锁竞争 |
| 内存 | 2MB 大页 + mempool | 提高 TLB 命中率 |
| 队列 | 无锁环形队列 | 核间通信 |
| 收发粒度 | 批量（burst 32） | 摊薄网卡访问开销 |

## 五、模块设计

```
收包 (PMD + RSS)
   ↓
解析 (Ethernet / IP / TCP-UDP)
   ↓
ACL 匹配 (五元组哈希 + 规则表)
   ↓
会话表 (哈希 + 老化)
   ↓
转发决策 (MAC 表 / FIB)
   ↓
发包 (批量 burst)
```

| 模块 | 职责 |
|---|---|
| `main` | EAL 初始化、参数解析、流水线启动 |
| `port` | 端口配置、启动、收发包封装 |
| `packet` | 报文解析与字段提取 |
| `acl` | 规则表结构、匹配算法、动态增删 |
| `session` | 会话表、超时老化、双向查找 |
| `forward` | MAC 表与 FIB 查找 |
| `stats` | 计数统计与周期性输出 |

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| 没有真机网卡 | 用 pcap PMD 或 virtio 在虚机 / WSL 里开发功能，性能测试再上真机 |
| 性能达不到预期 | 先保证功能正确，性能分阶段优化，只记录实际数据 |
| 时间不够 | 砍掉 L3 转发，只保留 L2 |
| DPDK 环境搭不起来 | 退一步用 AF_PACKET / AF_XDP 实现同样功能，技术含量略低但能完成 |

> 第一条是关键：**DPDK 支持 pcap PMD（从文件或虚拟接口收发）**，所以功能开发
> 阶段完全不需要真网卡，一台笔记本就够。这大幅降低了启动门槛。

## 十、面试准备清单

项目做完，下面这些问题要能脱稿讲清楚：

1. DPDK 为什么比内核转发快？（轮询 vs 中断、零拷贝、用户态、无锁、批量）
2. RSS 怎么工作？为什么必须保证同流同队列？
3. 大页为什么快？2MB 页和 4KB 页的 TLB 表项差多少？
4. 批量收发的收益从哪来？
5. 你的性能瓶颈是什么，怎么定位、怎么优化的？（最有分量的一题）
6. 无锁队列怎么实现的？为什么不用锁？
7. 会话表怎么解决哈希冲突？怎么处理老化？
8. 和内核转发比，DPDK 方案的代价是什么？
9. 如果让你支持 100G 线速，瓶颈会在哪？
